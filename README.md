# Axenda Visual FARO

Axenda visual dixital do Proxecto FARO para planificar e proxectar a xornada na pantalla dixital da aula.

## Que permite facer

- Crear e editar sesións.
- Organizar a semana.
- Gardar e reutilizar sesións.
- Proxectar a sesión no modo aula.
- Usar temporizador e avanzar polas actividades.
- Exportar e importar sesións en formato `.faro`.

## Uso

A aplicación funciona no navegador. Non precisa instalación.

Para unha publicación en GitHub Pages, o ficheiro `index.html` debe estar na raíz do repositorio e GitHub Pages debe estar activado para a rama que se use para publicar.

## Conexión a Internet

A aplicación consulta ARASAAC para buscar os pictogramas e cargar as súas imaxes. Polo tanto, a procura automática de pictogramas require conexión a Internet.
